# Skill: Documentation

## Objectif
Maintenir la documentation technique et fonctionnelle à jour.

## Conventions
- Sources de vérité :
  - `README.md`
  - `docs/cahier-des-charges-v1.0.docx`
  - `logo/eco.html`
- Toute nouveauté architecturale doit être documentée.
- L'agent de dev doit mettre à jour le README quand il ajoute un provider ou un module.

## Contraintes
- Pas de documentation générique copiée-collée.
- Distinguer clairement : MVP vs hors périmètre.

## Pièges à éviter
- Laisser le README en avance sur le code.
- Oublier de mentionner Earth Engine comme optionnel.

## Fichiers concernés
- `README.md`
- `docs/`
- `logo/`
